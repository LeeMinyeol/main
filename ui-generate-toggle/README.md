# Generate → Day / Week / Month 토글 — 15초 UI 마이크로 인터랙션

1080x1080 · 60fps · 15초 · 클릭 효과음 포함 MP4 (`generate-toggle.mp4`)
After Effects 없이 전부 코드(HTML Canvas + JavaScript)로 그리고, ffmpeg 로 영상으로 만듦.
첫 화면과 마지막 화면이 같아서 반복 재생하면 끊김 없이 이어짐.

## 다시 렌더하기

```bash
cd ui-generate-toggle
npm install            # 처음 한 번만 (이 폴더 안에만 설치됨)
npm run render         # → generate-toggle.mp4 (약 1분)
npm run preview        # → build/preview/ 에 확인용 스틸 이미지
```

## 무슨 일이 일어나나 (시간순)

| 시간 | 동작 |
|------|------|
| 0.0–0.8초 | 흰 캔버스 가운데 검정 알약 버튼 `✦ Generate` |
| 0.8–2.3초 | 커서가 오른쪽 아래에서 살짝 휘어진 경로로 버튼까지 이동. 2.0초에 호버: 버튼이 살짝 커지고 그림자가 깊어지며 ✦ 가 90° 회전 |
| 2.72–2.82초 | 클릭: 버튼이 눌렸다 튕기고 잔물결이 번짐 |
| 2.82–3.6초 | 버튼이 스프링처럼 늘어나며 토글로 변신. Generate 글자는 흐려지며 사라지고, 가운데 Week 부터 바깥쪽 순서로 글자가 나타나며 흰 선택 표시가 자라남 |
| 4.95초 | Day 선택 — 선택 표시가 젤리처럼 늘어나며 이동 (앞쪽 끝이 먼저, 뒤쪽 끝이 늦게) |
| 6.85초 | Month 선택 — 두 칸을 가로질러 이동 |
| 8.75초 | Week 선택 |
| 10.65초 | 토글 바깥 클릭 → 선택 표시·글자가 사라지고 다시 Generate 버튼으로 줄어듦 |
| 12.2–13.8초 | 커서가 화면 밖으로 나감 → 처음 화면과 같은 상태로 끝 |

디테일: 선택 표시가 글자 위를 지날 때 글자 색이 경계선에서 정확히 반반 갈림(흰색↔검정),
커서가 올라간 칸의 글자가 더 또렷해짐, 모든 크기 변화는 감쇠 스프링(살짝 넘쳤다 자리 잡는 움직임), 모션 블러 적용.

## 파일

- `src/main.js` — 애니메이션 전부. 맨 위 **타임라인(T)** 과 **디자인 값**(색, 크기, 글자)만 고치면 대부분 바뀜
- `audio.mjs` — 클릭·뽁 효과음 합성 (타임라인에서 시각을 그대로 받아와 화면과 항상 맞음)
- `render.mjs` — 브라우저로 한 프레임씩 그려 ffmpeg 로 MP4 제작
- 폰트: Inter (SIL Open Font License, npm `@fontsource/inter`)
